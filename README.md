[![rank](https://make.fun/badge/tiny-stack-vm-01-run-20261122/laithzz21/tiny-stack-vm-01-run-20261122/rank.svg)](https://make.fun/bounty/tiny-stack-vm-01-run-20261122)
[![reward](https://make.fun/badge/tiny-stack-vm-01-run-20261122/laithzz21/tiny-stack-vm-01-run-20261122/reward.svg)](https://make.fun/bounty/tiny-stack-vm-01-run-20261122)

A complete interpreter of make.fun's tiny stack ISA v1 for the
[Build a tiny stack virtual machine](https://make.fun/bounty/tiny-stack-vm-01-run-20261122)
bounty: 32-bit wrapping arithmetic, a 256-value stack, branches, calls,
256 words of memory, and all ten traps with their exact exit codes.
`node main.ts` answers every instance in `MAKEFUN_INPUT_DIR`
(default `/input`) into `MAKEFUN_OUTPUT_DIR` (default `/output`).
